四条学习路线

按目标学，不必机械从第一页翻到最后。

零基础

先把模型与训练链打通。

基础 → Transformer → Training → Inference

面试冲刺

优先覆盖追问最多的概念。

Transformer → Post-training → Serving → Eval

推理工程

关注延迟、吞吐、显存与多卡。

Inference → KV → vLLM/SGLang → Quantization

RAG / Agent

关注检索、工具、状态和安全。

RAG → Tool Calling → Agent Loop → Eval

7 天速成

每天要求“会画 + 会讲 + 会追问”，而不是只读完。

DAY 1

Transformer / BERT / GPT

必须能手画 Decoder Block，并解释 QKV、Causal Mask、RoPE、GQA。

DAY 2

Pretraining / Post-training

随机参数如何变成 Base Model，再变成 Chat / Reasoning Model。

DAY 3

Inference / Serving

Prefill、Decode、KV Cache、PagedAttention、TTFT/TPOT。

DAY 4

LoRA / Quantization / RAG

什么时候微调，什么时候 RAG，为什么 LoRA 省显存。

DAY 5

Agent / MoE

Tool Calling、Agent Loop、Memory、MCP、Router、Expert Parallel。

DAY 6

Eval / Hallucination / System Design

模型怎么选、怎么验证、怎么上线。

DAY 7

80 题 Mock Interview

每题先 30 秒，再 2 分钟，再连续追问两个 Why。

面试前必须能画出的 8 张图

不会画，通常说明知识还没有真正串起来。

① Decoder Block

Norm → Attention → Residual → Norm → FFN → Residual。

② Q / K / V

QK 匹配，V 承载被聚合的信息。

③ Encoder vs Decoder

双向可见与 Causal Mask。

④ Training Lifecycle

Pretrain → SFT → Preference/RL。

⑤ Prefill / Decode

为什么 Decode 依赖 KV 和内存带宽。

⑥ RAG Pipeline

Chunk → Retrieve → Rerank → Grounded Generation。

⑦ Agent Loop

Observe → Decide → Tool → Result → Continue。

⑧ Serving Scheduler

Queue → Continuous Batch → GPU → Stream。
