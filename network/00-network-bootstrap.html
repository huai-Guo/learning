为什么一开始没 IP 也能做 DHCP？
DHCP 本身就是“引导协议”。客户端在早期可以借助广播等机制发现 DHCP Server，不需要先拥有一个正常可用的单播 IPv4 地址。

4. DNS Server 从哪里来？

在家庭网络里，DHCP 经常把家庭 Router 自己发给客户端作为 DNS Server；Router 再把查询转给 ISP DNS 或公共 Resolver。企业网络、VPN、DoH/DoT 环境都可能不同。

Laptop │ DNS Server = 192.168.1.1 ▼ Home Router / Local Resolver ▼ Upstream Recursive Resolver ▼ DNS hierarchy / cache
!
“DNS Server = Router”不代表 Router 自己就是 Authoritative DNS
它经常只是本地代理、缓存或转发入口。
IPv6 不完全照搬 IPv4

5. IPv6：地址、网关和 DNS 也可以从不同机制获得

Router Advertisement

Router 可以通过 RA 告诉主机前缀、默认路由等信息。

SLAAC

主机可以根据前缀等信息自动形成 IPv6 地址。

DHCPv6

可用于补充或提供地址 / 其他配置；实际组合取决于网络策略。

6. 一页总结：在输入 URL 之前，网络其实已经准备好了

Wi-Fi / Ethernet 已加入网络 ↓ DHCP / RA / Static Config ↓ 得到本机地址 ↓ 得到 Subnet / Prefix ↓ 得到 Default Gateway ↓ 得到 DNS Server ↓ Browser 才有条件开始： URL → DNS → connect → TCP/TLS/HTTP
