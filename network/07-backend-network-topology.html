3 · CDN Cache Hit / Miss

Cache Hit

Edge 直接返回

用户请求不需要进入 Origin，因此后端 QPS 可能远小于边缘请求量。

Cache Miss

回源

Edge 再建立到 Origin 的连接，从源站取得内容并按策略缓存。

4 · WAF、L4、L7 分层

Firewall

更常基于 IP、Port、Protocol、Connection State。

L4 LB

按 Transport Connection 做分发，不必理解完整 HTTP Path。

WAF / L7

可以观察 Host、Path、Header、Cookie、Body，并做路由或安全策略。

5 · TLS 三种典型部署

Terminate

Client → TLS → Edge → HTTP → Backend。

Re-encrypt

Client → TLS A → Edge → TLS B → Backend。

Passthrough

Client → TLS → L4 LB → Backend，LB 不解密应用内容。

7 · 为什么 Backend 看不到原始 Client TCP Peer？

Client 1.2.3.4 ↓ Reverse Proxy 10.0.0.5 ↓ new TCP connection Backend 10.0.0.20 Backend TCP Peer = 10.0.0.5 原始 Client 信息需要： Forwarded / X-Forwarded-* / PROXY Protocol 并且必须建立 Trusted Proxy Boundary。

8 · HTTP Header 与 PROXY Protocol

X-Forwarded-For / Forwarded

属于 HTTP 层。客户端可以伪造，因此只应该信任明确的 Proxy 链。

PROXY Protocol

适用于更通用的 L4 Proxy 场景，可在真实应用数据前携带 Original Source / Destination。

14 · 数据库也还是网络

Backend Process ↓ DB / Redis Driver ↓ Socket ↓ TCP ↓ IP ↓ Private Network ↓ Redis / MySQL Server 所以： SQL 慢 ≠ 唯一故障源 还可能是 connect/read timeout、pool exhaustion、reset、DNS、route、packet loss。

15 · Readiness、Liveness、Draining

Liveness

进程是否坏到应该被重启。

Readiness

当前是否应该接收新流量。服务可以 Alive but Not Ready。

Connection Draining

停止分配新请求，等待 in-flight 请求完成，再优雅下线。

16 · API Gateway 与 Service Mesh

North-South · API Gateway

External Client → Internal System。常做 Auth、Rate Limit、Routing、API Policy。

East-West · Service Mesh

Service ↔ Service。常做 mTLS、Discovery、Retry、Timeout、Traffic Policy、Telemetry。
