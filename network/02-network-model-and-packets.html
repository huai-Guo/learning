4 · send() 返回，不代表“对面已经收到”

应用层

send() 常常只表示内核接受了待发送数据。

内核层

数据还可能排在 Socket buffer、拥塞控制、qdisc 或 Driver queue 中。

网络层

真正送达还需要链路、路由、对端 TCP 接收与 ACK。

7 · Driver / Ring / DMA / NIC 是什么关系

TX

发送

Kernel packet → qdisc → Driver → TX descriptors → DMA → NIC → 物理介质。Descriptor Ring 可以理解成驱动交给网卡的一圈“任务单”。

RX

接收

NIC → DMA 到 RX buffers → RX Ring → interrupt/NAPI → 协议栈 → Socket receive buffer → recv() → 应用。

8 · 为什么高性能网络要 NAPI / Offload

NAPI

避免每个包都硬中断 CPU，使用“通知 + 批量轮询”处理高包速接收。

GSO / TSO

发送方向把分段工作推迟到更低层或 NIC，降低 CPU 开销。

GRO

接收方向把多个相邻小包合并成更大的逻辑对象供协议栈处理。

10 · 记忆模型

应用只把字节交给 Socket；内核负责 TCP/IP、路由和邻居；驱动负责把 packet 交给网卡；NIC借助 DMA 与硬件队列真正发送和接收。
