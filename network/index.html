计算机网络扫盲：
从“输入一个 URL”开始，真正看懂网络

这不是一套“背 OSI 七层”的课。整套内容围绕一条真实 HTTPS 请求展开：URL → DNS → Socket → TCP → Route → ARP/NDP → NAT/PAT → Internet → TLS → HTTP → Gateway → RPC → Redis/MySQL。

适合谁

  • 第一次系统学习计算机网络的人。
  • 后端开发希望把八股、抓包、真实架构串起来的人。
  • 面试前需要用“因果链”而不是孤立题目复盘的人。

阅读原则

这套课程不靠“术语堆砌”，而靠四种图反复校准理解

参与者图

回答：Browser、Kernel、Router、Server 中，到底是谁在做这一步？

协议封装图

回答：HTTP / TLS / TCP / IP / L2 到底是什么上下层关系？

时序图

回答：谁先发什么，谁收到后再发什么？

状态 / 决策图

回答：为什么走这个分支？例如同网段 vs 默认网关、LISTEN vs ESTABLISHED。

!
一个图只回答一种问题
“HTTP 在 TLS 上面”和“Browser 在 Kernel 上面”和“Laptop 经过 Router 到 Server”属于三种不同关系，不能用同一根箭头混着画。

总母图：学完 01～07 后，你应该能独立解释这条链

Browser ↓ URL DNS / A / AAAA ↓ Happy Eyeballs / connect ↓ TCP SYN ↓ Route ↓ ARP / NDP ↓ NIC ↓ Home Router ↓ NAT / PAT（典型 IPv4） ↓ Internet Routing ↓ Server / Edge ↓ TCP ESTABLISHED ↓ TLS 1.3 ↓ HTTP / HTTP2 / HTTP3 ↓ CDN / WAF / LB / Gateway ↓ Service Discovery / RPC ↓ Redis / MySQL ↓ Response 返回

目前课程的主任务是把 01～07 的内容持续打磨成更易阅读、更统一的视觉化教学材料，不再继续新增第 08 章实验章节。
