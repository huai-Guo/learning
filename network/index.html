必须记住的六个边界

DNS ≠ 端口

DNS 主要把 hostname 解析成地址；443 通常来自 HTTPS scheme 或 URL 显式端口。

Happy Eyeballs 包含 connect 尝试

不是先选完 IP 再 connect，而是排序后错峰启动候选连接，谁先成功用谁。

Route 先于 ARP/NDP

先决定下一跳，再把“下一跳地址”解析成当前链路能使用的邻居地址。

NAT/PAT 属于路由器

它处理已经存在的 IP/TCP 报文，不是客户端协议栈中 TCP 之前的一个步骤。

CA 有两个时间轴

CA 事先签发证书；访问时浏览器主要在本地验证链和服务器私钥持有证明。

HTTPS 不等于必须 TCP

本教程第一主线使用 HTTP/1.1/2；HTTP/3 走 QUIC/UDP，会单独展开。
